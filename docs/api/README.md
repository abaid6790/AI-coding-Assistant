# API reference

All endpoints are prefixed `/api`. All request/response bodies are
JSON. Endpoints marked 🔒 require an authenticated session (and,
for state-changing methods, a matching CSRF header — see
`SECURITY.md`); everything else is reachable without one. This table
is generated by reading `server/api/*.py` directly, not written from
memory — see that directory for the authoritative source and
`server/services/` for what each route actually does.
